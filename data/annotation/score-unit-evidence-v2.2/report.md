## 规则与测试

先检验 index/offset/quote 与原文精确一致；非精确、错位、越界引文留在预测分母中，命中为 0，不做模糊修复。
每条预测内部去重引文，跨预测保留引用归属。精度要求与对应参考有重叠；召回要求覆盖参考区间 ≥50%。
互换两个子项的正确原文引文也不得分；同一 passage 的宽松命中不能代替严格证据归属。
补充引用计数 citation_counts：predicted/hit、gold/gold_hit、invalid；raw_citation_invalid_rate 仍取原运行 meta，不改历史调用信息。
真实 rescore CLI 回归覆盖正确拆分、整句大引文、互换子项引文、无关但逐字的引文、伪造引文、错误偏移、漏引用；
以及非精确/规范化金标候选、缺少证据、错误 passage、修订链断裂均在写结果前拒绝。
既有数字/否定守卫、漏项、预测不重用、父级分母等回归全部保留。

## 最小修正与局限

错误类别是匹配结果丢失子项身份，随后把所有引文同一份不完整父级证据比较；修正是在数据和匹配输入处保留身份与参考。
仍使用一个登记表和一套对齐器；只增加必要的修订链、子项关联与引用计数，没有新增模型、依赖或 CLI 配置。
只有语义上允许的拆分/证据需要用户授权；偏移、精确验证、归属和统计由代码计算，不让模型自行补金标。
金标证据完整性没有被证明覆盖整个数据集；词面配对、否定作用域和引用语义充分性仍有近似局限。
未放宽相似度门槛，也没有为 Kafka ID 或模型写特殊计分分支。
